# API TESTING RULES

For every feature implemented:

YOU MUST ALSO:
1. Provide Postman request
2. Provide sample request body
3. Provide sample response
4. Provide error cases

POSTMAN FORMAT:
- method
- url
- headers
- body
- expected response

BASE URL:
http://localhost:8000/api/v1

AUTH:
Use Bearer token

NO FEATURE IS COMPLETE WITHOUT TESTING

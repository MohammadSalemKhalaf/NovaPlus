# IMPLEMENTATION RULES

WORK STYLE:
- Implement step by step
- Do NOT generate everything at once
- Wait for confirmation between steps

ORDER:
1. Migration
2. Model
3. Relationships
4. Validation
5. Controller
6. Routes

REQUIREMENTS:
- Must match database schema exactly
- Must match API contracts exactly

EVERY FEATURE MUST INCLUDE:
- validation
- authorization
- error handling
- logging

NO SHORTCUTS
NO MOCK LOGIC
NO HARDCODED VALUES
